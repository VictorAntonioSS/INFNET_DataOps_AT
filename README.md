# TechNova - Plataforma de Dados

Projeto acadêmico de Engenharia de Dados desenvolvido na AWS.

## Objetivo
Construir uma plataforma moderna de dados utilizando:

- Amazon S3
- AWS Glue
- dbt
- Amazon Athena
- AWS Step Functions
- Amazon QuickSight
- AWS Lake Formation
- Apache Iceberg
